# Recipes v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the four-screen recipe PWA to `recipes.vicm.dev` with three seed recipes and the add-recipe skill.

**Architecture:** Recipes are JSON files bundled by `import.meta.glob`. Pure modules (`recipe`, `search`, `session`, `routes`, `clipboard-text`) carry the logic and the tests. React screens render them. One hash router in `app.tsx`.

**Tech Stack:** Vite 8, React 19, TypeScript 6 strict, vite-plugin-pwa 2, Vitest 5, oxlint, @fontsource Figtree and Fraunces.

**Spec:** `docs/superpowers/specs/2026-11-16-recipes-design.md`

## Global Constraints

- Colour tokens and type scale from `docs/design/design-brief.md`; exact values from `docs/design/screens/*.html`.
- No emoji in the UI. No shadows, no gradients. Text on accent is ink.
- `localStorage` key `session`. Session lifetime 24 hours, refreshed on Shop and Cook visits.
- Vite `base` is `/`. Routes are hash routes.
- Commits on `main`, `type(scope): subject`.

## Review Focus

- A session whose `recipeId` no longer exists (recipe file removed): Search hides the banner and drops the session. Test in Task 3.
- A `done` or `ticked` index beyond the recipe's length after a recipe file changes: treated as not done or not ticked. Test in Task 3.
- An ingredient chip typed with spaces or capitals ("  Butter Beans "): trimmed and matched case-insensitively. Test in Task 2.
- A duplicate chip: added once. Test in Task 2.
- A recipe file with an unknown `kind` or missing `steps`: `parseRecipe` throws with the file name in the message, so `pnpm test` names the bad file. Test in Task 1.
